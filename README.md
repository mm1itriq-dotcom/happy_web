# Your Happiness - Arabic Sentiment Analysis Web Application

**Author:** Gaith Hani Swaidan  
**Supervisor:** Eng. Mohammed al-heileh  

## Description
A web application that processes Arabic text sentences written by the user and determines their emotional state (Happy, Sad, or Neutral) using set-based string matching and emotion word ratios.

## Technologies
- **Frontend:** HTML, CSS, JavaScript (Vanilla Single Page Application)
- **Backend:** Python + Flask REST API
- **Database:** SQLAlchemy Core + Alembic + PostgreSQL
- **Security:** Password Hashing & JWT Token Protection
